The three typefaces in this directory are licensed under the SIL Open Font
License 1.1, which requires that this notice travel with them:

    "The above copyright notice and this permission notice shall be included
     in all copies of one or more of the Font Software typefaces."

Until now it did not. `fonts.css` named the designers and linked to
openfontlicense.org, which is attribution but not the permission notice, and a
licence you can only read online is the wrong shape for an instrument whose
whole claim is that it works on a machine that has never touched a network.

The copyright lines below are the ones embedded in the shipped .woff2 files
(name ID 0), read out of the binaries rather than transcribed. Where the
upstream project's own notice carries more than the subset does -- a Reserved
Font Name, a later contributor -- that line is included too and marked.

Google Fonts' subsetter strips name ID 13, the licence description, so these
files carry a licence URL and no licence text. That is why this file exists.
